# Tiisetso's Car Wash

A responsive car wash website built with React, TypeScript, Vite, Tailwind CSS, and Lucide.

## Run locally

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
npm run preview
```

## Business details

Update service prices, the South African WhatsApp number, phone, email, address, Google Maps URL, operating hours, optional special offer, and photo gallery in `src/businessConfig.ts`. Leave contact values empty until the owner has confirmed them. Booking enquiries open a WhatsApp message; a booking is not confirmed until the business replies.
